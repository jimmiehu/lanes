# Hub — how notes link

This note points at others in every way Lanes reads. The note it points at most is [[spoke]].

## Wikilinks

- `[[spoke]]` is a link by the note's file name: [[spoke]]. The name is enough while only one note in the vault has it.
- `[[links/spoke]]` is the same note by its path: [[links/spoke]]. The path is what to write when two notes share a name.
- `[[spoke|the note both point at]]` keeps the link and shows words of its own: [[spoke|the note both point at]].
- A person, by alias: [[ada-lovelace|Ada Lovelace]] keeps the plot next to ours, and [[grace-hopper|Grace]] cooks on Saturdays.

Type `[[` in WRITE and Lanes asks which note: two letters in, the vault's notes come up by title. Taking one writes the shortest link that lands, with the title as its words when the title and the file name differ.

## Markdown links

- To a note, by its path in the vault: [the rim](links/rim.md).
- To a note whose file name has a space in it: [Start here](Start%20here.md).
- To a page on the web: [example.com](https://example.com). That one opens in your browser.

## Paths written as prose

Claude names the files it wrote by their paths, so a path in plain text is a link too: projects/kitchen/bread.md. In backticks it is code, and a right-click on it offers to show the file in the Finder: `projects/kitchen/stock.md`.

## Following one

In READ a click follows a link and replaces this note in its tab; ⌘-click opens a tab of its own and leaves this one in the strip. In WRITE a plain click is a caret, so ⌘-click is the only way to follow.

A wikilink to a note that does not exist yet is not followed into nothing: in WRITE, ⌘-click makes the note and opens it, which is how one note grows another. A markdown link to a missing note makes nothing, and says so.
